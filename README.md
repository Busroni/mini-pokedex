# Mini Pokédex

Mini Pokédex adalah aplikasi berbasis React.js yang menampilkan daftar Pokémon serta detailnya menggunakan data dari PokeAPI. Aplikasi ini memungkinkan pengguna untuk mencari dan melihat informasi dasar mengenai setiap Pokémon.

### Fitur
- Menampilkan daftar Pokémon dengan gambar dan nama.
- Mencari Pokémon berdasarkan nama.
- Melihat detail Pokémon seperti tipe, statistik, dan kemampuan.
- Navigasi sederhana dengan tampilan responsif.

### Teknologi yang Digunakan
- React.js - Framework utama untuk membangun antarmuka pengguna.
- Tailwind CSS - Untuk styling yang cepat dan responsif.
- Axios - Untuk mengambil data dari PokeAPI.
- React Router - Untuk navigasi antar halaman.
